# 3D Previewer

Локальное веб-приложение для просмотра и проверки `.glb`-моделей игры ПВЗ перед тем, как они попадут в Godot.

- **Каталог.** Все модели из папки показываются карточками с миниатюрами, есть фильтры и поиск. Если файл меняется на диске, каталог обновляется сам.
- **Просмотр.** Можно вращать модель на поворотном столе, переключать пресеты света (день, ночь, студия), включать влажность, каркас, сетку, манекен ростом 1,8 м и габариты, делать скриншоты.
- **Проверка.** Приложение показывает ошибки и предупреждения glTF-валидатора, а также собственные проверки: неприменённый масштаб, подозрительный размер, модель не стоит на полу, нет UV или нормалей, исходник новее экспорта и другие. Видны статистика, материалы, текстуры и список объектов; объект можно выделить или скрыть.

## Требования

- Node.js 22 или новее (проверено на 22.17).

## Установка

```bash
npm install
npm run fetch:hdri   # один раз: HDRI для пресетов света (Poly Haven, CC0)
```

## Запуск

| Команда | Что делает | Адрес |
| --- | --- | --- |
| `npm start` | Собирает фронт и запускает сервер. Обычный режим работы. | http://127.0.0.1:4310 |
| `npm run dev` | Сервер и Vite с горячей перезагрузкой. Режим для разработки. | http://127.0.0.1:4311 |

## Папка моделей

Приложение читает `.glb` из папки моделей и следит за ней. Откуда берётся путь, по убыванию приоритета:

1. аргумент `--models-dir`: `npm start -- --models-dir ~/game/assets/models`;
2. переменная окружения `MODELS_DIR`;
3. поле `modelsDir` в `3d-previewer.config.json`. Его же можно поменять на странице «Настройки».

Файл `3d-previewer.config.json` создаётся автоматически при первом запуске:

```json
{
  "modelsDir": "./models",
  "host": "127.0.0.1",
  "port": 4310
}
```

Порт также можно задать переменной `PORT`. Миниатюры и прочий кэш лежат в `.cache/`, в папку моделей приложение ничего не пишет.

Если рядом с `.glb` лежит `.blend` с тем же именем, приложение считает его исходником модели. Для настенных моделей задайте в Blender Custom Property `placement: wall`, тогда проверка «не стоит на полу» к ним не применяется.

## Управление во вьювере

| Клавиша | Действие |
| --- | --- |
| `1` / `2` / `3` | Вид: общий / сверху / сбоку |
| `F` | Вписать модель в кадр |
| `R` | Вращение |
| `W` | Каркас: нет → поверх модели → только каркас |
| `L` | Следующий пресет света |
| `G` / `H` / `B` | Сетка / манекен / габариты |
| `P` | Скриншот |
| `Esc` | Снять выделение |
| `?` | Полный список клавиш |

Мышь: ЛКМ вращает камеру, колесо меняет масштаб, ПКМ сдвигает, двойной клик приближает к точке и делает её центром вращения.

## Прочие команды

- `npm run typecheck`: проверка типов TypeScript.
- `npm run build`: только сборка фронта в `web/dist/`.
